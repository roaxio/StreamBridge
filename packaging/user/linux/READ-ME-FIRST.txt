StreamBridge for Linux (x86_64)
===============================
Use your phone (e.g. the EZ-Cam app) as this computer's camera and microphone.

1. Extract the archive and run ./start-streambridge.sh (or ./StreamBridge). No Python needed.
2. The "Welcome / Setup check" window shows what is still missing:
   - v4l2loopback (camera). Install it with your package manager, e.g.
       sudo apt install v4l2loopback-dkms
     then load it (StreamBridge never runs this for you):
       sudo modprobe v4l2loopback devices=1 exclusive_caps=1 card_label="StreamBridge Camera"
     Details: https://github.com/umlaeute/v4l2loopback
   - PipeWire or PulseAudio with pactl/pacat (microphone). Most desktops already have it.
   Then click "Re-check".
3. Paste the video and/or audio URL your phone app shows and click Connect.
4. In your apps pick camera "StreamBridge Camera" and microphone "StreamBridge Microphone".

Settings: ~/.config/StreamBridge. To uninstall, delete this folder and ~/.config/StreamBridge.
The command line works too:  ./StreamBridge --help
